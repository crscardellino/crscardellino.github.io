En esta charla que di en la [FLISoL Córdoba
2026](https://librebase.org.ar/flisol-cordoba-2026/), doy una introducción a
cómo armar un LLM Homelab con ayuda de herramientas libres:
[Ollama](https://ollama.com/), para probar y servir LLMs locales;
[Open-WebUI](https://openwebui.com/), como interfaz de chat;
[SearXNG](https://docs.searxng.org/), para brindar a Open-WebUI servicio de
búsqueda web; y [OpenCode](https://opencode.ai/), como agentic coding tool.

La charla cuenta con un [repositorio de código (con
slides)](https://github.com/crscardellino/flisol-ai-homelab) y con un
[video](https://www.youtube.com/watch?v=6fHnfZ9qTiM).
